# TaskForge

A project management REST API built with Django and Django REST Framework.

## Tech Stack

- Python
- Django
- Django REST Framework
- Git & GitHub

## Overview

TaskForge is a backend engineering project designed to explore REST API development, database modeling, authentication, authorization, and software architecture.

## Development Goals

- Custom user model and email-based identity
- Project and task management
- RESTful API design
- Authentication and permission handling
- Automated testing
- PostgreSQL integration
- API documentation
- Docker and deployment
